STEP 1 — DEFINITIONS (pinned; a disagreement with any of these is a STOP for review, not an improvisation).
- Bars: a bar is {symbol, timeframe, open_ts, open, high, low, close} with open_ts ISO-8601 UTC; the bar's close time is open_ts + the timeframe interval. All series are sorted, gap-free synthetic series built by the fixtures.
- Scope: the predicate CONSUMES D1 bars as given. It never constructs D1 bars from intraday data and owns no session-calendar logic; session boundaries are the data supplier's business, in this order and in every later one.
- Levels, per symbol, from D1 bars: the structural level active at emission bar t comes from the D1 bar with the greatest close_time <= close_time(t) — the most recent COMPLETED D1 bar. The forming D1 bar (the one containing t) is NEVER a level source. The active structural levels are that D1 bar's high (d1_prior_high), low (d1_prior_low), and close (d1_session_structure). defined_at for a structural level is that D1 bar's close time. A level is active at bar t iff defined_at <= close_time(t) (non-strict, matching validator rule R1); a level born at an instant equal to a bar's close is active at that bar but cannot fire there, because it did not exist at t−1.
- Level identity and state: a level's identity is (level_type, level_price, defined_at). Crossing state is keyed to identity. A new D1 close mints new identities — a replaced level carries no state forward, even at the same price, so a sustained in-band dwell spanning a D1 close RE-FIRES under the new identity (at its second eligible bar: the birth bar cannot fire). This consequence is intended and is tested (case n).
- Grid levels: round numbers at multiples of the per-symbol grid_steps value from the param file (a param-file field; not an event-schema field). Every grid line is a level of type grid_round with defined_at = the param file's frozen_at, with its own crossing state; every grid line whose band is entered fires, one event per line.
- ATR: for an emission bar, ATR is the simple mean of true range over the atr_window (14) closed emission-timeframe bars immediately PRECEDING the emission bar. The emission bar itself is EXCLUDED — it never enters its own distance measurement. True range of a bar = max(high − low, |high − previous close|, |low − previous close|); the first bar of a series has no true range. distance_atr = |close − level_price| / ATR, measured at the emission bar's close; event_ts = the emission bar's close time. The param file carries atr_excludes_emission_bar: true declaring this construction; the predicate REFUSES a param file where that field is missing or false, and REFUSES a param file whose proximity_bands_atr does not hold exactly one band value (Phase 0 pins exactly one band) — refusal means raising an exception, not emitting events.
- Band and crossing: for each (symbol, emission timeframe, level identity): an event fires at emission bar t when distance_atr(t) <= band AND distance_atr(t−1) > band, where distance_atr(t−1) was measured against the level set active at t−1 (a level that did not exist at t−1 cannot fire at t). Distances are measured on CLOSES only — a bar whose high or low enters the band but whose close does not has not crossed. PINNED: crossings are evaluated on distance only — a gap-through whose landing close is inside the band fires (the event's claim is about the close's proximity, which is true); a gap-through whose landing close is outside the band does not fire, even if the bar's range spanned the level. The schema carries no side field and Phase 0 adds none. The first emission bar of a series never fires. No event fires until atr_window preceding bars with true ranges exist and a structural level exists.
- Crossing loop (normative pseudocode):
    for each symbol, for each emission timeframe:
      state = {}    # level identity -> distance_atr at the previous bar
      for t in emission bars, chronological:
        if fewer than atr_window preceding bars have true ranges, or no D1 bar has closed by close_time(t): continue
        atr = mean(true range of the atr_window bars immediately preceding t)
        active = structural levels from the D1 bar with greatest close_time <= close_time(t), plus all grid lines
        for level in active:
          d = |close(t) − level.price| / atr
          prev = state.get(level.identity)        # absent if the level was not active at t−1
          if prev is not None and prev > band and d <= band: emit(level, t, d)
          state[level.identity] = d
        drop state entries whose identity is not in active
  (Warmup arithmetic: with window 14 and bar 0 having no true range, the first emission bar that can fire is index 15, 0-based — it is the first with 14 preceding true ranges.)
- Event construction: each firing produces one event with exactly the EVENT_FIELDS of SCAN-001's schema: symbol, timeframe (the emission timeframe), level_type, level_price, defined_at, distance_atr (the firing bar's distance), atr_window and atr_basis and param_version from the param file, event_ts (the firing bar's close time). No extra fields, ever — R5 is a closed schema.
- Output ordering (determinism): events are emitted sorted by (event_ts, level_type, level_price, defined_at). Identical inputs produce byte-identical serialized output.

STEP 4 — FIXTURES AND TESTS. CONSTRUCTION CONSTRAINT: fixture numbers are chosen so every asserted distance_atr is exactly representable (e.g. flat true ranges making ATR exactly 1.0 wherever the case allows); the 1e-9 tolerance is a backstop, never the mechanism that makes an assertion pass. Expected event lists are asserted EXACTLY and COMPLETELY — all ten event fields per event (symbol, timeframe, atr_window, atr_basis and param_version included; they come from the param file and mis-wiring them is a plausible defect), not only the geometric fields. Cases:
(a) approach-and-enter: an H1 series that closes outside the band then inside it against the prior D1 high — exactly one event, at the entering bar;
(b) never-close: a series that never enters the band — zero events;
(c) start-inside: first bars already inside the band — no event until price exits and re-enters, then exactly one;
(d) dwell: several consecutive closes inside the band — exactly one event (the entry);
(e) gap-through landing inside: a close jumping from outside the band above the level to inside the band below it — exactly one event (the pinned distance-only rule);
(f) grid crossing: an approach to a round number — one grid_round event whose defined_at equals the test param file's frozen_at;
(g) both emission timeframes: the (a) geometry on H4 as well as H1;
(h) level replacement at a different price: a new D1 close replaces the levels mid-series — no event against a retired level, and a fresh crossing against the new level fires normally;
(i) validator integration: every emitted batch (events + a correctly built batch header) passes SCAN-001's validate_batch with valid == True — the assembled-path acceptance test;
(j) forming-D1 leak: the FORMING D1 bar's high sits inside the band at an emission bar while the completed prior D1 high does not — zero events (the completed-vs-forming discrimination);
(k) range-only touch: a bar whose high enters the band but whose close does not — zero events;
(l) close-bar attribution: a bar whose high entered the band on an earlier bar than its close does — the event is asserted on the close-based bar, not the range-based one;
(m) gap-through-and-out: a bar whose range spans the level but whose close lands outside the band — zero events (the complement of (e); together they kill a range-spanning implementation);
(n) rollover re-fire: an in-band dwell spanning a D1 close where the new D1 bar's corresponding level has the SAME price — the exact expected list shows the re-fire under the new identity at its second eligible bar (pin (iv)'s consequence, asserted, not assumed);
(o) born-inside: a level that comes into existence (new D1 close) while price is already inside its band — no fire until price exits and re-enters;
(p) simultaneous events: geometry where two levels are entered on the same bar (e.g. a narrow D1 bar's high and low, or two grid lines) — both events asserted, in the pinned output order;
(q) band edge: a bar at distance exactly == band with its predecessor > band fires; a bar at distance exactly == band whose predecessor was also exactly == band does not fire;
(r) ATR provenance: geometry where including the emission bar in the ATR would change distance_atr materially, with both candidate values exactly representable (e.g. preceding true ranges flat, the emission bar's true range large) — the asserted distance_atr is the EXCLUDED-bar value, so an including implementation fails by a wide margin, not by tolerance;
(s) param refusals: a param file with two proximity_bands_atr values is refused (exception); a param file with atr_excludes_emission_bar missing or false is refused;
(t) determinism: the predicate run twice over the same inputs, serialized with sort_keys=True, produces identical bytes.
