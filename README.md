# Scanline

Scanline is a standalone deterministic market-condition scanner. The validator is the deliverable and the modules are its evidence. Output is an offline research feed, never a live-decision input.

Sibling of Feedline and Watchline.

## Phase 0 Status

- **Universe**: GOLD, EURUSD, USDCAD, GER40, USOIL
- **Emission timeframes**: H1, H4
- **Definition timeframe**: D1
